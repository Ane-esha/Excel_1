## Data Exploration and Functions
# 1. SUM, COUNT, AVERAGE

- Calculate the total price of all products in the dataset.
- Count the number of products in the dataset.
- Calculate the average price of the products.

# 2. MIN and MAX

- Determine the minimum price among all products.
- Find the maximum price among all products.

# 3. IF Function

- Create a new column named "Price Range" using the IF function.
- Categorize products with a price greater than or equal to 500 as "High Price" and all other products as "Standard Price".

# 4. SUMIF and COUNTIF

- Calculate the total price of products in the "Electronics" category using the SUMIF function.
- Count the number of products with a price less than 100 using the COUNTIF function.

# 5. Text Formatting – LEFT, RIGHT, MID

- Create a new column named "Day" by extracting the first 2 characters from each "Product ID" using the LEFT function.
- Create a new column named "Country Code" by extracting the last 2 characters from the "Product ID" column using the RIGHT function.
- Create a new column named "Month" by extracting the 4th to 6th characters from the "Product ID" column using the MID function.
